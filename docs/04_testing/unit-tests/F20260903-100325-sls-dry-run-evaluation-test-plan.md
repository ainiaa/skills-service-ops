# 单元测试计划

| 场景 | 类型 | 断言 |
|---|---|---|
| dry-run | 正常/安全 | 输出时间范围和查询，`load_config`、凭据读取均未调用。 |
| 全部匹配 | 正常 | 判定器返回 `passed`。 |
| route 不匹配 | 异常 | 判定器返回 `failed` 和 `route` 原因。 |
| 重复、未知或缺失结果 | 异常 | 判定器返回 `failed`，并报告 `duplicate`、`unknown` 或 `missing`。 |
